# Pranav Srikrishnan — Portfolio

A full-stack React + Express personal portfolio featuring an editorial design system, interactive project showpieces, certificate viewer, library track, and responsive layout.

## Tech Stack
- **Frontend**: React 18, Vite, CSS3 Design System
- **Backend**: Node.js, Express, CORS
- **Styling**: Vanilla CSS with custom design tokens

## Getting Started

### Installation
```bash
npm install
```

### Running Locally
To run both the React frontend and Express server:
```bash
npm run dev:all
```

Or run them individually:
- Frontend: `npm run dev` (http://localhost:3000)
- Backend: `npm run server` (http://localhost:5000)

### Production Build
```bash
npm run build
```
